# 🏀 BallCut - 篮球进球集锦生成器

自动检测篮球比赛视频中的进球瞬间，按球员生成个人集锦。

---

## 🚀 快速启动

你可以通过我刚刚为你编写的跨平台启动脚本一键配置环境并启动：

```bash
python start.py
```
*(该脚本会自动检测操作系统、创建虚拟环境、安装所需依赖库，并启动 Web 服务)*

### 访问应用

启动成功后，请在浏览器中访问：**[http://127.0.0.1:8080](http://127.0.0.1:8080)**

---

## ✨ 核心功能

-   **智能检测**：AI 自动分析视频关键帧，定位篮球进球瞬间。
-   **局部重新检测**：整段检测后仍有遗漏时，在审核页选一段时间重新检测，可以换灵敏度和重新框选篮筐；结果与已有进球合并、按时间排序，不会重复。时间段可以在时间轴上拖出来、点进球卡片一键选中、或边看视频边打点，不用手填。
-   **历史记录**：首页自动整理历史处理记录，随时找回之前的进度；不需要的记录可以连同上传的视频一起删除。
-   **断点续跑**：检测过程中刷新页面或重启服务都不会丢进度，可以从上次检测到的地方继续。
-   **进球与助攻**：每个进球分“进球”“助攻”两栏，助攻可以填多个人。用过的名字自动记进名单，之后点名字按钮就行，不用重复输入。可以在回放窗口里看一段、点名字、回车看下一段；也可以在卡片上直接填，或者批量设置。每个人的集锦包含他进的球和他助攻的球。
-   **一键导出**：基于 FFmpeg 生成通用 MP4 集锦（H.264 + AAC），各种手机、电脑、微信里都能直接流畅播放。片段默认取进球前 6 秒到进球后 2 秒，可以在回放窗口里逐个调整（起点最多往前 15 秒）；片段起止与设定一致，拼接处画面逐帧连续、声音没有空隙。HDR（HLG）视频会转成普通色彩（BT.709，不压暗），最高 1080p、60 帧。有显卡时用显卡编码（NVIDIA 的 NVENC、Apple 芯片的 VideoToolbox），没有时用 CPU（x264）；画面需要重新编码，所以比直接截取慢，片段多时要等一会儿。

## 🛠️ 系统要求

-   **Python**: 3.9+
-   **FFmpeg**: 必需 (用于视频剪辑)
    -   Windows 用户请确保将 `ffmpeg.exe` 路径添加至系统环境变量。
-   **GPU (可选)**：支持 CUDA 可显著提升 AI 检测速度。
    -   **NVIDIA 显卡（Windows / Linux）**：`pip install torch` 默认装的是**不支持 CUDA** 的版本，检测只会用 CPU。需要手动安装带 CUDA 的版本：
        ```bash
        pip install --upgrade torch torchvision --index-url https://download.pytorch.org/whl/cu128
        ```
        RTX 50 系需要 CUDA 12.8 及以上。适合你机器的命令以 [PyTorch 官网](https://pytorch.org/get-started/locally/) 的选择器为准。
    -   `python start.py` 启动时会自动检查，显卡没被用上时会在控制台给出提示。
